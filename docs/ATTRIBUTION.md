# Attribuzioni

## Geografia

Made with Natural Earth. Free vector and raster map data @ https://www.naturalearthdata.com/.

Fonte: Natural Earth, Admin 0 Countries, scala 1:50m, GeoJSON dal repository ufficiale del curatore https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson . Scaricato il 29 ottobre 2026.

Licenza: pubblico dominio; https://www.naturalearthdata.com/about/terms-of-use/ . È compatibile con uso commerciale e modifiche. Modifiche: esclusione Antartide, proprietà ridotte, coordinate arrotondate a 4 decimali, nomi italiani e punti etichetta forniti dal dataset; aggiunti valori di bilanciamento. Il file trasformato è incluso in `public/data/world.geojson`.

Natural Earth adotta confini de facto, include territori e aree contese: la mappa non costituisce una dichiarazione di sovranità. Il contatore 241 riguarda entità geografiche del dataset, non 241 Stati sovrani.
